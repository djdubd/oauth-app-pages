Privacy policy

Last updated 2026-11-21.

health-step-tracker has one user: the person who built it. It reads only that person's own Google Health data, with read-only access, after they sign in and agree.

  • The data goes to a single server the user owns and runs at home. It is never sold, shared, or sent to anyone else.
  • The app collects nothing from anyone else, and this website sets no cookies and runs no tracking.
  • The access token is stored only on that server. The user can revoke it at any time at myaccount.google.com/permissions.

Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
